# FixiFy Municipality Web Dashboard

This is the React.js + Vite dashboard for FixiFy municipality users.

## Prerequisites
- Node.js (v18+)
- Mapbox Public Token

## Getting Started
1. Install dependencies: `npm install`
2. Create `.env` file from `.env.example` and add your Mapbox token.
3. Start the dev server: `npm run dev`

## Tech Stack
- React 18, Vite
- Tailwind CSS
- React Router DOM
- Zustand (State Management)
- React Query (Data Fetching)
- Mapbox GL JS
